# Madhu Sri Crackers - Official Website (React + Vite + Tailwind CSS)

A modern, fast, and responsive e-commerce landing page for **Madhu Sri Crackers** (Sivakasi Fireworks), built strictly according to the design mockup.

---

## 🚀 Features

- **Built with React + Vite + Tailwind CSS**: Lightning fast development and production builds.
- **Pixel-Perfect to Design**:
  - Top Announcement Bar with festival notices & trust badges
  - Modern Header with Active Navigation pills and action buttons
  - Hero section with ambient fireworks canvas and 3D cracker stack showcase
  - 4 Key Value Proposition cards
  - Explore Crackers Collection (6 Categories: Flower Pots, Sparklers, Rockets, Ground Chakkars, Fancy Fountains, Gift Boxes)
  - Our Best Sellers (Sky Shot, Colour Sparklers, Flower Pots, Ground Chakkar) with real discount calculations
  - Festive Celebration Promo Banner with animated glowing Diwali Diya
  - "Why Choose Us?" 4 assurance pillars
  - Customer Testimonials (Arun Kumar, Priya Sree, Vikram)
  - Newsletter Subscription Strip
  - Comprehensive Footer with Sivakasi contact details and social media
- **Interactive Capabilities**:
  - 🛒 **Slide-over Shopping Cart Drawer**: Add to cart, adjust quantities, calculate subtotal and festival savings.
  - 💬 **One-Click WhatsApp Order**: Pre-fills an organized WhatsApp message with selected crackers and prices to the Sivakasi store number.
  - 🔍 **Live Search Modal**: Type any cracker name or category to search in real time.
  - ❤️ **Wishlist Toggle**: Save favorite crackers for Diwali.
  - 🎆 **Interactive Fireworks Canvas**: Gentle sparkling particle animation in the Hero header with click-to-burst effect.
  - 📱 **Fully Responsive**: Optimized for mobile, tablet, and desktop screens.

---

## 🛠️ Quick Start

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```

### 3. Preview Production Build
```bash
npm run preview
```
